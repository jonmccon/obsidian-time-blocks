Time Blocks — Google Calendar authorization

This page hands your authorization code back to you so you can paste it into Obsidian. It does not send your data anywhere — everything here happens locally in your browser.

Authorization succeeded. Copy the code below and paste it into the Time Blocks plugin's settings pane in Obsidian to finish connecting Google Calendar.

  1. Click Copy code above (or select and copy the text manually).
  2. Switch back to Obsidian.
  3. Open Settings → Time Blocks → Google Calendar.
  4. Paste the code into the "Authorization code" field and confirm.

Prefer a shortcut? Open in Obsidian attempts to hand the code straight back to the plugin via an obsidian:// link — this only works if Obsidian is installed and running, and is not required. If nothing happens when you click it, use the copy/paste steps above instead; they always work.

You can safely close this tab once you've copied the code.

Authorization did not complete.

Go back to Obsidian and try connecting Google Calendar again from Settings → Time Blocks → Google Calendar. If this keeps happening, check that the OAuth client configured in Google Cloud Console matches the plugin's settings.
